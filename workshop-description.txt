[h1]勤务机器人 · 地图划区指挥[/h1]
把原版瓦器人 W.O.B.O.T. 升级成独立工作机器人，帮助农场、渔场和营地分担日常劳动。

[h2]如何开始[/h2]
服务器启用模组，加入的玩家也需下载。在炼金引擎旁使用：瓦器人 ×1、电子元件 ×2、木板 ×4。
把机器人放到地上。打开原版地图，点击“机器人管理”→“新建区域 · 框选”，用鼠标拖出工作区，选择任务并勾选机器人，点击“应用工作区域”。全程不需要输入聊天命令，也不需要 API。

[h2]地图工作区域[/h2]
一个矩形区域最大 160×160（约 40×40 块地皮），可分配最多 16 台机器人，每个分片最多保存 32 个区域。农田和配套箱子放在区域内；区域、工作任务和分配随存档保存。
点击已有区域可以调整任务和成员，或暂停、继续、删除。地图显示区域边框和机器人编号，可直接点击机器人勾选。地图指挥不受旧聊天命令的 80 距离限制；仅显示当前分片的机器人。远处休眠仍遵循原版加载机制，附近有玩家后继续工作。

[h2]能做什么[/h2]
[list]
[*]种田：从附近箱子拿种子，在已有土堆播种，照料、收菜并补耕。
[*]收鱼：收取能从岸边接近的原版海洋拖网捕鱼器，保留鱼饵并恢复下网状态。
[*]搬运：收拾地面物品；绑定补给箱和交货箱后，可在两个箱子之间搬运。
[*]做饭：从同一补给箱取一份肉类和三个浆果，在空锅制作肉丸。
[*]站哨：守卫固定区域，简单近战；不主动攻击玩家、同伴、已有主人的跟随生物或首领。
[/list]

[h2]多机器人指挥[/h2]
推荐直接在地图中勾选机器人。原版聊天命令仍可使用：
/robot 列表
/robot 选择
/robot 命名 小农
/robot 加选 小渔
/robot 编组 农田组
/robot @农田组 种田
/robot @农田组 暂停

一次最多控制同分片、已加载、80 距离以内的 16 台机器人。名字和组名存档；编号可能随读档改变。组内可保留各自的工作中心和箱子绑定，多台机器人会避开彼此已经预约的目标。

[h2]更大范围与防卡住[/h2]
未划区的新机器人默认圆形半径 24，可用 /robot 半径 80 调整；已有存档保留原值，划区后以矩形边界为准。
任务时间根据路程计算，卡住后最多尝试 3 次可通行路点绕行。仍无法到达时会释放任务、延长目标冷却并转做其他工作。不会瞬移或穿墙；封闭围墙、跨海和船仍需玩家安排通路。

[h2]可选 DeepSeek[/h2]
常用命令不需要联网、不需要密钥、消耗 0 token。只有启用本机桥接后的复杂指令才交给 AI；整组一条指令只请求一次。
桥接需在服务器电脑运行 Python 程序并配置自己的 DEEPSEEK_API_KEY，默认关闭，默认仅房主/管理员可触发收费解析。带缓存、每日预算和冷却，不发送全服聊天或世界地图。使用者自行承担 API 费用。具体安装步骤见 GitHub README；未使用真实密钥测试 API。

[h2]当前范围[/h2]
需要玩家先准备农田和初始土堆；暂不浇水、施肥、收巨大作物，也不自动乘船。做饭目前仅支持肉丸，站哨暂不支持巡逻路线。机器人有 6 格货仓，300 耐久，给予石头可修复。捡起即可停止和搬家。
外观复用原版瓦器人动画并带浅蓝色调。封面由 AI 生成，是功能示意，非游戏截图。
v0.2.0 已通过 24 项真实服务器引擎检查、10 项真实客户端地图与网络指令检查、10 项导航组件测试和 6 项桥接测试。两个真实玩家同时操作的走查尚未完成。
