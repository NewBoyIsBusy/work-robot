# 勤务机器人

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3829656195) · [GitHub 源码](https://github.com/NewBoyIsBusy/work-robot)

《饥荒联机版》服务器模组，当前版本 **0.3.0**。它消耗原版瓦器人 **W.O.B.O.T.（`storage_robot`）** 制作一台独立工作机器人。玩家直接右键机器人进入设置视角，再右键世界中的箱子、冰箱、植株、捕鱼器、锅、物品或敌人，决定这一台机器人要处理什么。

0.3 不再使用 `/robot` 命令和地图划区面板，全部功能均不需要 API。

## 制作和使用

1. 在炼金引擎旁使用 **瓦器人 ×1、电子元件 ×2、木板 ×4** 制作勤务机器人。
2. 把机器人放到地面，右键选择“设置机器人”。镜头会先来到机器人处，之后不会锁定跟随。
3. 在设置视角中右键工作对象。再次右键同一对象即可移除。
4. 右键机器人，或按 `Esc`，退出设置视角。

| 操作 | 作用 |
| --- | --- |
| `W A S D` | 自由移动镜头，便于设置远处目标 |
| `R` | 重新把镜头移回机器人 |
| 鼠标右键 | 添加或移除箱子与工作目标 |
| `G` | 把当前镜头中心设为站哨点 |
| `X` | 取消站哨点 |
| `Esc` | 退出并恢复玩家镜头 |

设置时玩家角色不会跟着 WASD 走动。机器人可以继续工作；绿色线段显示它当前前往的目标和必要的下一段路线。

## 可以选择的目标

| 目标 | 机器人行为 |
| --- | --- |
| 普通箱子、冰箱等容器 | 作为材料来源及交货箱；可以同时选择多个 |
| 农作物、普通可采植株、石果灌木 | 照料、施肥和采集；需要的种子或肥料从已选箱子取用 |
| 农田土堆 | 从已选箱子取种子并播种；缺养分时尝试取可部署肥料 |
| 海洋拖网捕鱼器、陷阱 | 收取产物 |
| 烹饪锅 | 从已选箱子取食材做肉丸 |
| 地面物品 | 拾取并送进已选箱子 |
| 普通敌对生物 | 简单近战；不会主动选择玩家、同伴或首领 |

箱子既是补给来源，也是收货地点。易腐物会优先送入拥有原版 `preserver` 效果的容器，也识别冰箱和食物保鲜标签；同等保鲜条件下优先合并已有物品堆。每次存放会尽量移动整组物品，不再逐个慢慢放。

机器人只处理玩家明确选中的对象。目标及箱子随存档保存；目标毁坏后会自动从列表移除。每台机器人最多保存 48 个箱子和 48 个工作目标。

## 维修、战斗与寻路

机器人受伤或损坏时，右键它选择“维修机器人”。一次消耗一块石头并恢复 60 点耐久；先检查玩家物品栏，再检查该机器人的目标箱子。完全损坏的机器人仍可右键维修。

站哨点附近出现普通敌对生物时，机器人会进行简单近战。它不会主动攻击玩家、玩家同伴、已有主人的随从或史诗生物。

移动使用原版寻路。机器人会监测是否前进；卡住时尝试有限的可达路点，失败后释放目标并稍后重试。它不会瞬移、穿墙、跨海或自动乘船，所以围墙仍需留门，岸边捕鱼器也必须能从陆地接近。

## 安装与升级

Steam 版订阅后，在世界的服务器模组列表中启用“勤务机器人”；房主和加入的玩家都需要安装，洞穴分片也需启用。

手动安装时，把发布包中的 `work_robot` 文件夹放入游戏 `mods` 目录。不要同时启用 Steam 版和手动版。

旧存档中的机器人会保留实体和耐久。0.2 的区域、聊天选择、分组和补给/交货箱设置不再使用，需要按 0.3 的方式重新右键选择目标。

## 当前限制

- 做饭当前只支持肉丸。
- 农田仍需玩家先准备耕地和土堆。
- 不会自动浇水、建造、乘船或处理巨型作物。
- 路线线段表示当前行动目标，不是完整的原版寻路网格。
- 远处区域仍遵循原版世界加载和休眠规则。

0.3.0 已使用真实 DST 专用服务器验证任务、保存、修理、战斗和自主搬运，并使用真实客户端渲染器验证右键进入、自由镜头、远程目标选择、多目标路线显示和退出恢复镜头。
