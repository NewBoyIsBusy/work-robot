# 勤务机器人（原版聊天窗指挥）

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3829656195) · [GitHub 源码](https://github.com/NewBoyIsBusy/work-robot) · [v0.1.0 安装包](https://github.com/NewBoyIsBusy/work-robot/releases/tag/v0.1.0)

与同系列模组相同，Steam 工坊设为仅好友可见；GitHub 源码和安装包公开。工坊版和手动安装版只选一个启用。封面由内置 Imagegen 生成，为功能示意，并非游戏截图；提示词见 `assets/cover-prompt.txt`。

《饥荒联机版》独立服务器模组，首版 0.1.0。消耗原版瓦器人 **W.O.B.O.T.（storage_robot）** 制作独立机器人。支持农活、收鱼、搬运、做肉丸、站哨和简单战斗。通过**原版聊天窗**指挥单台或整组机器人，可选用 DeepSeek 理解自然语言。外观复用原版瓦器人动画，带浅蓝色调。

## 制作和使用

1. 把 `work_robot` 文件夹放进游戏的 `mods` 目录，在世界的服务器模组列表启用“勤务机器人”。房主和加入的玩家均需安装。洞穴分片也需单独启用。
2. 在炼金引擎旁解锁配方：**瓦器人 ×1、电子元件 ×2、木板 ×4**。配方位于科学和种植分类。制作会消耗原版瓦器人，产出新的勤务机器人。
3. 用耕地机准备农田，再用锄头规划最初的土堆；在附近普通箱子中放入种子。
4. 把机器人从物品栏放到地面，放置点成为工作中心。默认半径 12，约三块地皮宽。
5. 机器人会从箱中取一粒种子，走到土堆播种；照料生长中的作物；收获成熟普通作物后，在原位置补耕并继续播种。
6. 收获、地面物品和捕鱼器中的鱼会被搬入范围内的箱子。优先放入已有同类物品的箱子，也能使用空箱。种子按附近箱子、槽位顺序选择。
7. **捡起机器人即可停工和搬家**，携带的货物会掉在地上；重新放下会设置新工作中心。存档保存工作中心和携带物品。

## 原版聊天窗指挥

按游戏原来的聊天键输入下面的命令，回复显示在原版聊天记录中。机器人指令不会作为普通聊天广播，也不会把普通聊天内容发送给 AI。使用 `/robot 帮助` 查看命令。

先右键机器人选择“指挥机器人”，或靠近后输入 `/robot 选择`。不带名字时选最近 6 距离内的一台。后续命令控制所选机器人，通信范围为同分片内 80 距离。

| 指令 | 作用 |
| --- | --- |
| `/robot 种田` | 开启播种、补耕、收菜、照料和地面搬运 |
| `/robot 只收菜，不播种` | 只采收普通成熟作物，并交货 |
| `/robot 收鱼` | 收取可到达的岸边海洋拖网捕鱼器 |
| `/robot 搬运` | 捡地面物品；指定不同补给箱和交货箱后，可在这两个箱子间搬运 |
| `/robot 做饭` | 用一份生肉/小肉/怪物肉加三个浆果，在空的普通烹饪锅做肉丸 |
| `/robot 站哨` | 在工作中心附近待命，攻击范围内符合条件的敌对生物 |
| `/robot 暂停`、`/robot 继续` | 停工或继续已有任务 |
| `/robot 状态` | 查看各台当前任务、半径、绑定箱子 |
| `/robot 半径 12` | 设置所选机器人的工作半径，接受 4–20 的整数 |
| `/robot 中心` | 把所选机器人的工作中心移到玩家脚下 |
| `/robot 补给箱`、`/robot 交货箱` | 绑定玩家 4 距离内最近的可用箱子，要求位于机器人工作范围内 |
| `/robot 解绑` | 恢复自动选择箱子 |
| `/robot 自动工作` | 恢复农田、收鱼、搬运组合；做饭和战斗需单独下令 |

任务预设会替换当前的任务组合。交货一直可用，不会因为关闭地面搬运而把已有货物卡在身上。箱子绑定后不会擅自改用别处箱子；箱子损毁或移出范围时需要重新绑定。

## 多机器人和编组

`/robot 列表` 显示附近机器人的名字、当前编号和组名。编号随重新加载世界可能变化，**名字和组名会存档**。名字重复时用列表中的编号精确选择。

```text
/robot 选择
/robot 命名 小农
/robot 加选 123456
/robot 编组 农田组
/robot @农田组 种田
/robot @农田组 暂停
```

其中 `123456` 要替换成列表里实际显示的编号。也可以用 `/robot 选择 小农`、`/robot 加选 小渔`、`/robot 选择组 农田组` 或 `/robot 选择全部`。一台机器人属于一个组，一次最多选 16 台；只控制当前加载、同分片、80 距离内的成员。没有找到成员时明确提示，超出距离的成员不接收命令。组内成员可保留不同工作中心和箱子绑定。

任务预约由服务器共享，机器人会跳过别台正在处理的目标。整组下达一条 AI 指令时，只发一次请求，再把经过校验的任务设置应用给各成员。等待 AI 时发出新命令或切换选择，会使旧响应失效，防止旧指令覆盖“暂停”。

## 支持的工作

| 工作 | 当前行为 |
| --- | --- |
| 播种 | 使用箱子中的普通种子、作物种子，在已有土堆种植 |
| 补耕 | 在收获后留下的塌陷土堆补耕，保持原来的种植布局 |
| 照料 | 调用原版照料接口，各生长阶段需要时再次照料 |
| 收菜 | 采收成熟的普通农作物，保留原版产量规则 |
| 收鱼 | 收取岸边可步行接近的原版海洋拖网捕鱼器 `ocean_trawler`，保留鱼饵，恢复收鱼前的下网状态 |
| 搬运 | 将可拾取地面物品和自己的货物放入附近普通储物箱；优先同类归仓 |
| 做饭 | 从补给箱取一份肉类和三个浆果，装入空锅并烹饪肉丸，完成后收锅交货；不接管玩家已经装料的锅 |
| 站哨/战斗 | 固定区域守卫，攻击敌对生物或正在攻击玩家/机器人的目标；不主动攻击玩家、同伴、已有主人的跟随生物和带原版首领标签的生物 |

模组设置中的默认工作半径可设为 8 / 12 / 16 / 20，聊天命令可为每台调整。机器人有 6 格内部货仓，当前版本无需额外燃料或工具。机器人 300 耐久，近战伤害 20，攻击间隔至少 1.5 秒；低于或等于 20% 耐久停止主动战斗，耗尽后损坏停工。**给予石头，每个恢复 30 耐久**，损坏不会销毁机器人及其货物。

## 可选接入 DeepSeek

常用命令完全在游戏内识别，**不需要桥接、不需要密钥、消耗 0 token**。复杂指令才交给 DeepSeek 转为任务设置，例如选中机器人后输入 `/robot 守着农田，顺便收菜`。无法支持的数量、时间表、执行先后、具体物品筛选或未实现动作会被拒绝，不执行生成的代码。

启用方式：

1. 在运行游戏服务器的电脑上安装 Python 3，把 `DEEPSEEK_API_KEY` 设置为该进程可读的环境变量。密钥仅留在服务器环境中，不写入模组文件或游戏聊天。
2. 启动：`python work_robot/bridge/bridge.py --enable-deepseek`。该程序只监听服务器本机 `127.0.0.1:8765`。
3. 在服务器模组设置中启用“DeepSeek 本机桥接”，重新加载世界。专用服务器、地面/洞穴分片可以共用同一个桥接程序。远程服务器需要把桥接运行在远程服务器上。
4. 默认只有房主/管理员能触发收费的 AI 解析；可通过“允许所有玩家使用 AI”放开。普通本地指令供所有玩家使用。

默认模型为官方文档当前的 `deepseek-flash`；可通过 `DEEPSEEK_MODEL` 环境变量调整。关闭思考模式，最多输出 256 token；不发送聊天历史、世界地图、玩家标识或逐帧状态，只发送本次指令和所选机器人共有的任务设置。模型输出只允许白名单中的布尔开关、半径和肉丸食谱。

重复指令按“文本＋当前共有设置”缓存，最多 128 条，重启桥接后清空。每天默认保守预留预算 20,000 token（按 UTF-8 字节数和输出上限估算，通常会早于真实额度耗尽而停用），可用 `--daily-tokens` 调整；预算记录保存在服务器用户目录 `.work_robot/usage.json`，重启不会重置当天记录。每小时最多 30 次模型调用，单玩家至少间隔 10 秒。超时不自动重试；断网、无密钥、额度不足或响应不合规时保持原有任务。

桥接验证使用模拟模型返回值，**没有调用真实 DeepSeek API，也没有产生 API 费用**。配置密钥后仍需用实际账号做一次联机验证。

## 使用边界

- 第一块农田及初始种植布局由玩家准备；机器人不会自行开辟农田、改变地皮。浇水、施肥、除草暂需玩家处理，因此不保证低压力产量或巨大作物。
- 保留巨大作物、腐烂作物和杂草，不自动采收或敲碎；避免破坏留作展示的巨大蔬菜。
- 收鱼只支持原版海洋拖网捕鱼器，且需能从陆地走到收取距离内；不自动乘船、游泳，也不支持第三方模组的自定义捕鱼器。原版起网可能释放溢出的鱼，遵循原版行为。
- 默认搬运指地面/收获/捕鱼器到箱子；只有明确绑定不同补给箱和交货箱并开启搬运后，才执行箱子之间的搬运。播种和做饭也会取用补给箱。不会取玩家背包或切斯特里的物品。
- 使用中的、只读的、带权限限制的、燃烧或烧毁的箱子会跳过。箱子没有足够空间时，停止收取新的地面物品；已有货物留在机器人身上等待。收菜会检查至少三个空货仓格。
- 多个机器人共享任务预约；目标被别人拿走、箱子拒收或走不到目标时，重新检查并暂时跳过。拒收时归还物品。
- 离开加载范围后暂停实际行动，回到附近恢复工作。船上的机器人暂停工作。
- 做饭当前只有肉丸食谱，材料必须在同一个补给箱内能凑齐；站哨是固定区域守卫，尚无自定义巡逻路线或跟随玩家作战。使用原版接口，不提供人物专属加成。
- 移除模组前，请先捡起机器人并回收掉落的货物；新增机器人无法在禁用模组后继续存在。
